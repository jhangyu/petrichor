# Petrichor v2 — Drop as Lens (v2-icon-4-opus)

**Concept.** One big glossy raindrop is a lens: looking into it you see the radar — eccentric reflectivity
bands (light rain → heavy core) and a translucent sweep wedge. A soft cloud sits in front of the drop's
upper-left shoulder and casts a shadow onto the glass. Merge: the cloud produces the drop, the drop *is*
the radar view — cloud + rain + radar echo read as one object, not three icons.

**Fluent 2 traits.** 3 major forms (drop, echo cell, cloud); generous radii, no strokes; layered overlap
(cloud over drop, bands stacked with soft lift shadows, sweep wedge translucent over bands); multi-stop
linear + radial gradients in every shape; top-left key light (glass sheen + tip specular), cyan rim light
bottom-right; soft contact shadow under the drop and under the cloud; light brand-tint background with a
white top-left glow and faint violet accent bottom-right.

**Palette.** Background #F4F9FF → #DCEBFC → #B6D4F7, glow #FFFFFF, accent #D9D2FA.
Drop #7CC4FF → #2886DE (brand-90) → #0E4775 (brand-50), rim #7FE3F5.
Echo bands from `--dbz-*`: #C4F0FF/#6FD0F5 (dbz-0), #4BDDA4/#1FA65A (dbz-20), #FFE766/#F2C600 (dbz-30),
#FFB04A/#FF7A00 (dbz-40). Cloud #FFFFFF → #EEF5FE → #B9D5F5. Dark bg #16304D → #050D18.

**Construction (108 grid).** Drop circle centre (58,60) r 19.5, tip at 1.78 r with rounded apex.
Cloud = three tangent-to-baseline circles (34.5,43,r7.5) (47,36.5,r11) (59.5,45,r5.5), baseline y 50.5.
Echo bands centres drift toward lower-right (58,62.4)→(61.3,66.7), r 14.6/10.9/7.1/3.6, low-order wobble.
Monochrome: drop with two band gaps (evenodd) + cloud separated by a 2-unit gap (evenodd clip).
Generated by a script so all variants share exact geometry; max content radius 29.9 of the 33 safe radius.

**Masks.** All content within r 29.9 of centre → survives circle, squircle, every M3 shape incl. cookie,
sunny, gem, pentagon. Background is full-bleed gradient only, content-free at edges (parallax-safe).
iOS: full-bleed square, no alpha; dark = navy bg with same lit forms; tinted = grayscale on black.
macOS: 824 body r 185, baked soft shadow, edge highlight.

**Weaknesses.** At 16 px the echo bands merge to a coloured dot inside a blue drop and the white cloud is
low-contrast on the light background — reads as "drop + something". Band stack can read as a target/egg
yolk to some eyes; the sweep wedge is what says "radar". Asymmetric composition (cloud left, drop right).
